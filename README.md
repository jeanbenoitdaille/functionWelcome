# Function Welcome

Exercice C# sur la création d’une méthode avec paramètre et valeur de retour.

## Objectif pédagogique

Manipuler :

- une méthode d’instance ;
- un paramètre `string` ;
- une valeur de retour `string` ;
- l’interpolation de chaînes avec `$"..."`.

## Fonctionnement

La méthode `SayHello(string name)` retourne un message de bienvenue de la forme `Bonjour <nom> !`.
